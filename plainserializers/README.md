# Serializadores planos

Estos modelos convierten un XML con relación 1 a 1. Sin simplificaciones de navegación.

No toma en cuenta tipos de dato, todo lo hace como strings.

Respeta si un campo es opcional o requerido

Todos los modelos disponibles pueden encontrarse [aquí.](https://github.com/SaulEnriqueMR/documentacion-sat/tree/main/xsd)

NOTA: Los nodos llevarán el prefijo de la versión. Por ejemplo si estamos en el modelo de Comprobante 4.0. El nodo principal se llama Comprobante40, el Emisor será Emisor40 y así subsecutivamente.
